# COACHING-L ポモドーロタイマー

集中するための道具であると同時に、自分の集中パターンに「気づく」ための道具です。
集中が散漫になりやすい方や、スケジュール管理が苦手な方が、気軽に使えることを目指しています。

提供：コーチングスクール COACHING-L

- ブラウザだけで動く静的サイトです（インストール・登録は不要）
- 記録はこの端末の中だけに保存され、外部には送信されません

## 使い方

1. **スタート**：「この時間で、何をする？」に、やることを一行で書きます（空欄でも始められます）。
   作業時間を 10分 / 15分 / 25分 から選ぶか、「その他」で 5〜60分を入力して「はじめる」を押します。
   休憩時間（初期値5分）は「設定」で 1〜30分に変えられます。
2. **集中の時間**：残り時間と、書いた宣言が表示されます。「一時停止」と「やめる」が使えます。
   「やめる」を押しても、それまでの時間は「中断」として記録に残ります。
3. **振り返り**：時間になるとチャイムが鳴ります。集中度（1〜5）と気分を選んで「休憩へ」を押します。どちらも選ばずに進んでもかまいません。
4. **休憩**：休憩タイマーと、身体を休めるひとことが表示されます。時間になるか、「スタートにもどる」を押すとスタートに戻ります。
   ひとことは20種類あり、トランプを切るように順番を混ぜて出すので、20種類を一巡するまで同じ文は出ません。文は `app.js` の `breakPrompts` に書き足せます。
5. **記録**：スタート画面の「記録」から、日ごと・週ごとの記録を見られます。
   - **日ごと**：今日・昨日・おととい…と前後の日に動けます。その日のまとめと一覧のほか、任意の「この日のふりかえり」（よかったこと／次に試したいこと／気持ちが動いたこと）を書けます。書いた内容は自動で保存されます。「この日をコピー」で、その日の記録を LINE などに貼れる文章にできます。
   - **週ごと**（月曜はじまり）：その週のまとめ、日ごとの集中の時間のグラフ、集中しやすい時間帯（ここ4週間）、没頭できた時間（集中度5の回）、その週のふりかえり、ふりかえりの問いを見られます。
   - **記録のダウンロード**：表計算ソフト用（CSV）と、バックアップ（JSON）をダウンロードできます。CSV は Excel・Numbers・Googleスプレッドシートで文字化けせずに開けます。バックアップには記録・ふりかえり・設定がすべて入ります。iPhone では「ファイル」アプリの「ダウンロード」に保存されます。
   - **バックアップの読み込み**：「バックアップを読み込む」でバックアップ（JSON）のファイルを選ぶと、その記録とふりかえりを、今の端末に足せます。新しいスマホへの引っ越しや、Safari に記録を消されたあとに使えます。
     - 足す前に「記録○回と、ふりかえり○日分を足します」と中身を見せるので、確かめてから「この端末に足す」を押します。
     - 今ある記録は消したり書き換えたりしません。同じ記録（同じ記録ID か同じ開始時刻）は1つにまとめるので、同じファイルを2回読み込んでも二重になりません。ふりかえりは、空の欄にだけ足します。
     - 設定（作業時間・休憩時間・表示など）は読み込みません。端末ごとの設定のままです。
     - iPhone・iPad では、出てきた一覧の「ファイルを選択」から、「ダウンロード」にあるファイルを選びます。
     - ファイルを選べないとき（LINE などのアプリの中で開いたときなど）は、元の端末で「バックアップを文字で表示」の文章をコピーし、「文字で貼り付けて読み込む」に貼り付けます。
   - 記録やグラフは、評価ではなく自分のリズムに気づくためのものです。平均・比較・連続日数は出しません。詳しくは [SPEC-records.md](SPEC-records.md) を見てください。
6. **表示の切り替え**：「設定」の「表示」で、自動／ライト／ダークを選べます。「自動」はスマホやパソコンの表示設定に合わせます。

### ちょっとした仕様

- ページを再読み込みしたり、タブを閉じて開き直したりしても、進行中のタイマーは続きから表示されます。
  閉じている間に時間が過ぎていた場合は、「完了」として記録したうえで、終わった時刻を添えて振り返り画面を表示します。

### チャイムと通知について

- **スマートフォン・タブレット**：画面が消えている間や、別のアプリを使っている間は、ブラウザがページの動きを止めるため、チャイムは鳴りません。
  そのため、タイマーの間は画面が自動で消えないようにしています（「設定」の「タイマーの間は、画面をつけたままにする」。スマートフォンとタブレットでは初期値オン、パソコンでは初期値オフ）。
  - この機能は https で公開したページ（GitHub Pages など）と、対応するブラウザでだけ働きます。使えないときは「設定」にその旨が表示されます。
  - ページが読み込み直されたあと（別のアプリから戻ったときや、ブラウザを開き直したときなど）は、画面に一度触れるまでチャイムと「画面をつけたまま」が効かないことがあります。そのときはタイマー画面に案内が出ます。
  - 電源ボタンで画面を消したときや、別のアプリに切り替えたときは鳴らないので、このページを開いたままにしておいてください。
  - iPhone・iPad では、マナーモード（消音モード）のときもチャイムは鳴りません。
- **スマートフォン・タブレットの通知**：ブラウザからは通知を出せません。
- **パソコンの通知**：「設定」の「終了時に通知する」を押して許可すると、終了時にブラウザの通知も届きます。
  許可したあとに出る「テスト通知を送る（5秒後）」で、実際に届くかを確かめられます。
  届かないときは、パソコン側の設定を確認してください。
  - Mac：「システム設定 → 通知」で、使っているブラウザ（Google Chrome など）の「通知を許可」をオンにする
  - Windows：「設定 → システム → 通知」で、通知とブラウザをオンにする
  - 集中モード・おやすみモード（応答不可）の間は表示されません

## プライバシー

- 記録と設定は、お使いのブラウザの `localStorage`（キー：`coachingl-pomodoro-v1`。ふりかえりは `coachingl-pomodoro-notes-v1`）にだけ保存されます。
- アプリから外部へ送信することはありません。ダウンロードやコピーをした記録は、あなたが選んだ相手にだけ渡ります。
  バックアップを読み込むときも、ファイルはこの端末のブラウザの中だけで読み、どこにも送りません。
- 外部への通信は一切しません。解析ツール、Cookie、外部フォント、CDN も使っていません。
  `index.html` の Content-Security-Policy で、外部への接続そのものも禁止しています。
- 記録は端末・ブラウザごとに別々です。別の端末と同期されることはありません。
- 記録を消したいときは、「記録」→「すべての記録を消す」を押してください（ふりかえりも一緒に消えます）。
  ブラウザの「サイトデータを削除」でも消えます。
- iPhone・Mac の Safari は、しばらく開かなかったサイトの保存データを自動で消すことがあります。
  ときどき「バックアップ（JSON）」をダウンロードしておくと安心です。消えてしまったときは「バックアップの読み込み」で戻せます。
- **記録の保存場所は、開き方ごとに別々です。** 次の場合、それまでの記録は自動では引き継がれません。移したいときは、元の開き方で「バックアップ（JSON）」をダウンロードし、新しい開き方の「バックアップの読み込み」で読み込みます。使い始める前に、どこで開いて使うかを決めておくのがおすすめです。
  - iPhone（iOS 26 以降）でホーム画面に追加したアイコンは、既定で「Web アプリ」として開き、Safari とは別の保存場所になります。
  - LINE などのアプリの中で開いたページは、そのアプリの中に保存されます。Safari や Chrome で開き直しても表示されません。
  - コーチが LINE で URL を送るときは、末尾に `?openExternalBrowser=1` を付けると、LINE の中ではなく端末のブラウザで開きます。
- GitHub Pages では、同じ持ち主のページどうしで保存場所（オリジン）が共通になります。同じ持ち主のほかのページから、この記録を読み書きできてしまう点に注意してください。

## ローカルでの動作確認

ビルドは不要です。リポジトリのフォルダで簡易サーバーを起動し、ブラウザで開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

`index.html` をダブルクリックして直接開いても動きますが、通知は `localhost` か `https` でしか使えないため、サーバー経由での確認をおすすめします。
「画面をつけたままにする」機能も `localhost` か `https` でしか動きません。スマートフォンから `http://<パソコンのIP>:8000/` で開くと「https で開いたページでだけ使えます」と表示されるので、スマートフォンでの確認は GitHub Pages で公開してから行ってください。

確認するときのポイント：

- 作業時間を「その他」で 5分にすると、短い時間で一連の流れを試せます。
- 進行中に再読み込みしても、残り時間が続きから表示されること。
- 開発者ツールの「Application → Local Storage」で、保存内容を確認できます。
- 開発者ツールの「Network」タブで、ページ自身のファイル以外への通信がないことを確認できます。

## GitHub Pages での公開

1. このリポジトリの `main` ブランチに、`index.html` / `style.css` / `app.js` がある状態にします。
2. GitHub のリポジトリ画面で **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で「Deploy from a branch」を選びます。
4. **Branch** で `main`、フォルダは `/ (root)` を選んで **Save** を押します。
5. 1〜2分ほど待つと、`https://<owner>.github.io/<リポジトリ名>/` で公開されます（`<owner>` はリポジトリの持ち主の名前です）。
   公開された URL は、同じ Pages の画面の上部に表示されます。

更新するときは、`main` に変更を反映するだけで、自動的に公開内容も更新されます。

`style.css` や `app.js` を変えたときは、`index.html` の `style.css?v=8` / `app.js?v=8` の数字を1つ上げてください。
GitHub Pages ではファイルがブラウザに10分ほど保存されるため、数字を上げないと、新しい `index.html` と古い `app.js` が組み合わさって表示が崩れることがあります。

```
SPEC.md      MVP の仕様書
SPEC-records.md  記録とふりかえり（第2段階）の仕様書

```

### app.js の構成（拡張するときの目安）

| ブロック | 内容 | 今後の拡張との関係 |
| --- | --- | --- |
| `STRINGS` | UI の文言をすべて集めたオブジェクト | 中国語対応は `STRINGS.zh` を追加し、`LANG` を切り替える |
| `DEFAULTS` / `loadConfig()` | 作業時間・休憩時間などの既定値 | URL パラメータでの設定は `loadConfig()` で上書きする |
| `Store` | localStorage への保存・読み込み（`version` 付き） | データ形式を変えるときは `migrate()` に移行処理を足す |
| `Timer` | 終了予定時刻から残り時間を計算 | — |
| `Sound` / `Notify` | チャイム（Web Audio API）と通知 | PWA 化するときは Service Worker の通知に置き換えられる |
| `ScreenLock` / `syncScreenLock()` | タイマーの間、画面を消さない（Screen Wake Lock） | — |
| `Notes` | 一日のふりかえりの保存（本体とは別のキー） | — |
| `summarizeDay()` / `summarizeRange()` / `summarizeBands()` | 日・期間・時間帯ごとの集計 | 画面・ダウンロード・コピーで同じ集計を使う |
| `renderRecords()` / `renderDailyChart()` / `renderBands()` | 記録画面とグラフ（SVG を組み立てる。外部ライブラリなし） | — |
| `buildCsv()` / `buildJson()` / `buildDayText()` | ダウンロードとコピーの中身 | — |
| `parseBackup()` / `diffBackup()` / `confirmImport()` | バックアップの読み込み（中身の確認 → 足すものを選ぶ → 保存） | `buildJson()` の形を変えたら `formatVersion` を上げ、`parseBackup()` で古い形も読めるようにする |
| `renderers` / `showView()` | 画面ごとの描画と切り替え | 雑念メモや質問カードは、画面（`section[data-view]`）を追加する |

### 保存データの形式

```js
{
  version: 1,
  settings: { workMinutes, breakMinutes, keepScreenOn, theme },  // keepScreenOn は未設定なら端末の種類で決まる。theme は "auto" | "light" | "dark"
  sessions: [{
    id, startedAt, endedAt,          // 時刻はミリ秒（epoch）
    plannedMinutes, intention,
    status: "completed" | "interrupted",
    focus: 1〜5 | null,
    feeling: "refreshed" | "fulfilled" | "neutral" | "tired" | "foggy" | "rushed" | null,
    focusedSeconds                   // 実際に集中した秒数（一時停止中は含まない）
  }],
  current: null | {
    phase: "focus" | "review" | "break", endAt, remainingMs, ...,
    finishedLateAt                   // 1分以上遅れて終了に気づいたときの終了時刻（それ以外は null）
  },
  promptDeck: { remaining, last }    // 休憩のひとことの山札
}
// 知らない項目は捨てずに残します（新しい版で足した項目を、古い版で消してしまわないように）

// 一日のふりかえり（キー：coachingl-pomodoro-notes-v1）
{
  version: 1,
  days: { "2026-10-06": { good, next, moved, updatedAt } }   // 各200字まで。全部空になった日は消す
}

// バックアップ（JSON）のファイル（coachingl-pomodoro_data_YYYYMMDD.json）
{
  format: "coachingl-pomodoro-data",
  formatVersion: 1,                  // 読み込むときは、この版より新しい形は読まずに再読み込みを案内する
  exportedAt: "2026-10-06T21:00:00+09:00",
  settings, sessions, days           // 進行中のタイマーと休憩のひとことの山札は入れない
}
```

気分は表示名ではなくキーで保存しています。表示名は `STRINGS` の `feelings` から引くので、言語を切り替えても過去の記録をそのまま表示できます。
